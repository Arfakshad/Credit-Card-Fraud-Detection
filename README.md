# 💳 Credit Card Fraud Detection

A Machine Learning web application that detects fraudulent credit card transactions using predictive analytics. Built with Python, Scikit-learn, and Streamlit, the application enables users to upload transaction data, analyze datasets, and receive real-time fraud predictions through an intuitive web interface.

## 🚀 Live Demo

https://arfakshad-hekbl5zi2c7hpmpflfp7yy.streamlit.app/

## 📌 Features

- 💳 Detect fraudulent credit card transactions
- 📂 Upload CSV files for batch prediction
- 📊 Interactive dataset analysis dashboard
- 📈 Fraud distribution visualization
- ⚡ Real-time machine learning predictions
- ⬇ Download prediction results as CSV

## 🛠️ Tech Stack

- Python
- Streamlit
- Scikit-learn
- Pandas
- Plotly
- Joblib
